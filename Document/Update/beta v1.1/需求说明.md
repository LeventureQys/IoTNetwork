# 需求说明

总的需求说明：

当前这个配网流程为v1.0版本，写的相对较为复杂，但是现在这个v1.1，实际上是一个简化版本，这个配网流程将会变得十分简单，我需要你做好业务层上的裁剪工作，包含PC端程序和设备端程序的业务端流程都需要进行大幅度裁剪。

需要注意的是，你应该需要修改的只有业务层代码，硬件层不要做过多修改。

1. 整体配网简化，只考虑设备一对一的情况，PC端会主动打开一个名称为Modu_xxx的wifi，然后esp32设备上电后需要主动扫描这个名称类型的wifi，其中，这个wifi需要带上密码，密码为modu_leventure

2. 连上之后，PC端设备需要检查自己的ip，按理说应该是一个固定IP，然后这个固定ip是PC设备端限定好的，文档中会约定这个ip，如果不是，pc端程序需要自己想办法。pc端程序会在5935端口开启tcp服务器。

3. 连上之后，device端程序会主动尝试连接到指定ip的指定端口的tcp，建立握手、心跳包连接。

4. 二者就可以通信了。
