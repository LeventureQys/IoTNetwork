## 5. 启动测试

在当前 Linux 设备上使用 sudo：

- 普通首选网段启动。
- 使用 dummy 路由制造首选冲突并验证备用选择。
- 非法配置 fail-closed。
- UDP 67占用失败和退避。
- `iw`、`ip addr`、`ss`、`/proc` 交叉验证。

- 至少执行一次完整启动路径；20次启停可留到阶段四，但推荐阶段三提前执行。
