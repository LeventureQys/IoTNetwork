# 设计文档 - v1.0.6 文档更新说明

## 1. 背景与目标

v1.0.5 完成了代码完全拆分（PC/Device 分离、纯C边界管理），是一次超大更新。v1.0.6 需要产出工程更新说明文档，帮助嵌入式开发者理解硬件抽象层架构并完成 ESP32-C2 移植。

**目标**：产出4份 Word 文档（.docx）放入 `Document/移植说明/`，同时确认抽象层设计是否清晰完整。

## 2. 交付物清单

| 序号 | 文件名 | 目标读者 | 风格要求 |
|------|--------|---------|---------|
| 1 | `ESP32移植指南.docx` | 嵌入式开发者 | 简洁，纯任务清单（checkbox），可打勾执行 |
| 2 | `ESP32移植方案.docx` | 嵌入式开发者 | 简洁，逐条细化接口契约与约定值，无具体代码 |
| 3 | `配网流程说明.docx` | 嵌入式开发者/团队 | 简洁，零代码，带流程图，覆盖设备端+上位机端 |
| 4 | `验收说明.docx` | 嵌入式开发者（自验） | 可以详细，含验收项与验证步骤 |

**源文件**：每个 .docx 由对应的 .md 源文件通过 Python 脚本（`scripts/md_to_docx_v2.py`）转换生成。.md 源文件保留在 `Document/移植说明/` 目录下。

**定位**：给嵌入式工程师的开工清单，每条可打勾，无需理解上下文即可逐条执行。

**结构**：
```
1. 前置准备（开发环境、ESP-IDF版本、工具链确认）
2. 项目骨架集成（源文件复制、CMake组织）
3. 后端接口实现（29个接口的 TODO 清单，按类别分组）
   - 生命周期（2条）
   - WiFi 介质（9条）
   - TCP 非阻塞（6条）
   - UDP 组播（3条）
   - mDNS（3条）
   - NVS（3条）
   - 系统函数（2条）
4. ESP-IDF 集成（sdkconfig、partition、事件循环）
5. 编译与烧录
6. 功能验证（配网→发现→连接→心跳→自愈 逐阶段验证）
```

**禁止写入**：代码片段、ESP-IDF API 详细说明。

### 3.2 ESP32移植方案

**定位**：给嵌入式工程师的接口契约参考，说明每个接口"做什么"、"用什么ESP-IDF API"、"有哪些约定值"。

**结构**：
```
1. 硬件抽象层概览（net_backend_t 架构说明，vtable 总览表）
2. 生命周期接口（init/deinit）
3. WiFi 介质接口（9个，含 SSID 命名规则 Modu_XXXX、PIN 4位数字、WPA2密码约定）
4. TCP 接口（6个，含端口 5935、非阻塞语义、AGAIN 映射）
5. UDP 组播接口（3个，含组播地址 224.0.2.1:5936）
6. mDNS 接口（3个，含服务类型 _tactile._tcp）
7. NVS 接口（3个，含命名空间 "provision"、键名约定）
8. 系统接口（2个，time_ms/random）
9. 关键约定值速查表（全部参数集中一张表）
10. 常见陷阱与注意事项（STA异步、单核事件循环、mDNS点号规则等）
```

**接口描述模板**（每个接口用半页）：
```
### wifi_sta_connect
- 功能：连接指定 WiFi（STA 模式）
- ESP-IDF API：esp_wifi_set_mode → esp_wifi_set_config → esp_wifi_connect
- 约定值：reason code 映射表（201/202/203/204/205 已对齐 ESP-IDF wifi_reason_t）
- 返回值：DEMO_OK / DEMO_ERR
- 注意：ESP-IDF 为事件驱动，需用事件组同步阻塞等待
```

**禁止写入**：完整的 C 代码实现。

## 4. 流程图生成方案

### 4.1 当前问题分析

现有 `scripts/draw_flowcharts.py` 存在的问题：

| 问题 | 原因 | 影响 |
|------|------|------|
| 布局凌乱 | `nodesep=0.25`, `ranksep=0.3` 间距过小 | 节点文字重叠，边缘紧贴 |
| 线条穿透 | `splines=polyline` 在复杂图中产生穿越节点的边 | Fig002A 多处交叉 |
| 悬垂引用 | Fig001B 引用了 Fig002C 的节点（d20, d22） | 跨图无定义节点 |
| 文本溢出 | 节点 label 有多行但 `fontsize=8` 未留足空间 | 文字被截断或溢出 |

### 4.2 改进方案

1. **增大间距**：`nodesep=0.5`, `ranksep=0.6`，节点 `margin="0.15,0.1"`
2. **使用正交路由**：`splines=ortho` 替代 polyline，线条走直角不穿节点
3. **移除跨图引用**：每个图独立，不引用其他图的节点 ID
4. **添加隐性排序约束**：用 `rank=same` 和隐形节点控制并行分支对齐
5. **精简节点文本**：每节点最多 3 行，fontsize 9
6. **增加颜色可读性**：保持现有的颜色语义（绿=开始/成功、蓝=过程、黄=判断/等待、红=错误/结束）
7. **DPI 提升**：`dpi=200` 确保在 Word 中清晰

### 4.3 生成流程

1. 运行改良版 `scripts/draw_flowcharts_v2.py`
2. 输出到 `figures/` 目录（PNG, 200 DPI, 白色背景）
3. md_to_docx 脚本在转换时自动读取并嵌入图片
