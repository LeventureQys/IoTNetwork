## 说明

1. 最终的成果我想要你放入Document\移植说明 这个目录下

2. 需要你写至少两个文档：1. esp32移植指南 2. esp32 移植方案 3. 验收说明

3. 移植指南中，请你不要在这个文件中带有任何代码，只需要说明任务，以及 todo list，让嵌入式在迁移的流程中可以有一个非常明确清晰的方向，可以一条条打勾过点

4. 移植方案中，则需要根据移植指南中的一条条过点，细化到每一点需要做哪些工作，但尽量不要写非常具体的代码，你只需要告诉开发你需要做什么事，比如抽象层中的哪个接口，你需要做哪些事情，里面有哪些细节是约定出来的。举个例子，比如wifi的名称，以及PING码，端口等等。

5. 请你根据当前的最终改动之后的代码，将二者的配网流程组织成一个文档（原来git中是有这个docx的文档的，但是后续删掉了，你可以读一下，然后按照那个形式去写一篇零代码，带流程图的配网流程文档）
