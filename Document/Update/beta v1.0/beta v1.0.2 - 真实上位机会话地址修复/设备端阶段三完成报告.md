## 2. 实现摘要

- 新增纯函数 `sim_tcp_resolve_endpoint()`：输入运行模式、请求端点、模拟 AP 匹配信息、模拟 Host 端点；输出最终 IPv4/端口（均网络字节序）。
- 真实 Linux 设备模式判定：`__linux__ && dev_index() >= 0 && use_real_wifi_sta`。
- `TcpConnect()` 仅用 helper 结果构造 `sockaddr_in`，不做二次 `htonl/htons`；socket 创建、非阻塞 connect、select 超时、SO_ERROR 和关闭分支保持原结构。
- 端序实现采用字节组装方式（端序无关），避免在不同机器上写出反转地址。
